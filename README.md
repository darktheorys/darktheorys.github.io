# darktheorys.github.io

Personal site. Single static `index.html`, no build step, no dependencies.
Served by GitHub Pages from `main`.

https://darktheorys.github.io/

## Resume

`burak-omur-resume.tex` is the source for `burak-omur-resume.pdf`:

    pdflatex burak-omur-resume.tex

Rebuild and commit both together, then mirror any content change into
`index.html` by hand (the page is not generated from the LaTeX).
